# Catálogo Interativo de Produtos

## Descrição do projeto

Este projeto consiste no desenvolvimento de um catálogo interativo de produtos, criado como atividade da disciplina de Programação Web. A aplicação permite visualizar produtos, pesquisar por nome, consultar detalhes e gerenciar uma lista de favoritos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API DummyJSON
- LocalStorage

## Funcionalidades

- Listagem dinâmica de produtos consumidos por meio de uma API.
- Exibição de imagem, nome e preço dos produtos.
- Pesquisa de produtos pelo nome.
- Visualização dos detalhes dos produtos.
- Tradução das descrições para português.
- Adição e remoção de produtos dos favoritos.
- Armazenamento dos favoritos utilizando LocalStorage.
- Exibição da lista de produtos favoritos.
- Interface responsiva.

## API utilizada

DummyJSON Products API:

https://dummyjson.com/products

## Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` utilizando a extensão Live Server.
4. Acesse o catálogo pelo navegador.
